# Oil_and_Gas_Production
Oil & Gas Production Analytics Dashboard – Project Description
PROJECT DESCRIPTION

Oil & Gas Production Analytics Dashboard is an end-to-end Business Intelligence project developed using Microsoft Power BI to analyze and monitor oil and gas production operations. The main objective of this project is to transform raw operational data into meaningful insights that help management evaluate production efficiency, monitor well performance, identify operational downtime, control operating costs, and measure monthly production target achievements.

The project integrates five datasets: Fields, Wells, Production, Operating Costs, and Monthly Targets. Using Power Query, the data is cleaned, transformed, and standardized. A Star Schema data model is developed to establish relationships between dimension and fact tables. DAX measures are implemented to calculate important performance indicators such as Total Oil Production, Total Gas Production, Uptime Percentage, Cost per Oil Barrel, and Monthly Target Attainment Percentage.

The Power BI dashboard provides interactive visualizations to analyze production trends, compare field performance, identify high-producing wells, monitor downtime, and evaluate operating cost efficiency. It also helps identify operational challenges such as excessive downtime, increasing production costs, and underperforming wells.

Key findings from the analysis include Bravo Offshore accounting for 52% of total operational downtime, an 18% increase in operating cost per barrel during Q3, and Delta Shale achieving 104% of its monthly production target.

The project also provides business recommendations, including preventive maintenance, cost optimization, improved water treatment practices, and automated operational monitoring using SCADA telemetry alerts.

Overall, this project demonstrates how Power BI, Power Query, data modeling, and DAX can be used to convert complex operational data into actionable business intelligence, supporting better decision-making, improved production efficiency, and effective resource management.

Key Technologies Used
- Power BI Desktop: Interactive dashboards and visualizations.
- Power Query: Data cleaning and transformation.
- DAX: KPI calculations and analytical measures.
- Star Schema: Structured data modeling.
- Power BI Service: Dashboard publishing and sharing.
- Excel/CSV: Operational dataset management.
